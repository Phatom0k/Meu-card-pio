# Meu Cardápio V3

PWA pessoal para cardápios e pedidos. Inclui estoque por dia, montagem de prato temporária, mesas A1-A6, B1 quadro, B2 porta, B3, B4, B5 meio, B6 peixe e Entrega; pedidos pendentes, concluídos e cancelados; cancelamento devolve os itens ao estoque; Service Worker e manifest para PWA.

Para publicar no GitHub Pages, coloque estes arquivos na raiz de um repositório público e habilite Pages na branch main. O PWA exige HTTPS para o Service Worker funcionar.

Os dados desta V3 são locais ao dispositivo. Sincronização entre vários celulares e uma central exigirá backend/banco de dados em versão futura.
